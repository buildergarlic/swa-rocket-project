경남 로켓 발사 프로젝트 · 전자칠판 실행 방법

1. 이 압축 파일을 전자칠판 PC의 바탕화면에 풀어 주세요. (오른쪽 클릭 → 압축 풀기)
2. 풀린 폴더 안의 index.html 을 오른쪽 클릭 → 연결 프로그램 → Chrome(또는 Edge)으로 엽니다.
3. 오른쪽 위 ⛶ 버튼(또는 F11)으로 전체 화면을 켭니다.
4. 위쪽에서 오늘 수업하는 학교와 반을 누릅니다. (반마다 진행 상황이 따로 저장됩니다)
5. 화면을 한 번 눌러 주세요. 브라우저는 화면을 한 번 누른 뒤부터 소리를 냅니다.
6. 부품이 도착하면 부품 번호 버튼을 누르거나 키보드로 번호를 칩니다. (예: 2, 7 → 27번)
   잘못 눌렀으면 같은 버튼을 다시 누르면 취소됩니다.
7. 36개가 모두 모이면 "발사대로 옮겨 발사하기" 버튼(또는 스페이스 키)을 누릅니다.
   이송 → 기립 → 카운트다운 → 발사 → 인공위성 분리 → 축하 자막 순서로 약 1분 동안 나옵니다.
   재생 중 스페이스는 잠시 멈춤, Esc는 닫기입니다.

수업 전에 꼭 확인할 것
- 설정(⚙️) → "발사 장면 미리 보기"로 소리와 화면을 확인하세요.
- 소리는 전자칠판 스피커 음량을 크게(70% 이상) 올려 주세요. 외부 스피커나 우퍼를 연결하면 훨씬 웅장합니다.
- 인터넷이 없어도 동작합니다.
- 인터넷이 안 되거나 프로그램이 안 열릴 때는 함께 드린 "발사영상_학교이름.mp4" 파일을 대신 틀면 됩니다.
