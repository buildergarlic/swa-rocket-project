# 경남 로켓 발사 프로젝트 · 전자칠판 화면

햄스터봇 창의융합 수업(초등 5·6학년)에서 전자칠판에 띄우는 화면입니다.
아이들이 햄스터봇 택배로봇으로 경남 곳곳의 부품 업체에서 로켓 부품을 발사대까지 옮기면,
화면의 로켓이 한 부품씩 완성되고 36개가 모두 모이면 발사 영상이 나옵니다.
발사대는 실제 발사장인 **고흥 나로우주센터**입니다(지도에서는 경남 서남쪽 가장자리에 표시).

## 여는 방법

- 설치가 필요 없습니다. 이 폴더를 USB나 전자칠판에 복사한 뒤 `index.html`을 **크롬(또는 엣지)** 으로 여세요.
- 인터넷이 없어도 동작합니다. (인터넷이 있으면 글꼴이 조금 더 예뻐집니다.)
- 오른쪽 위 ⛶ 버튼으로 전체 화면을 켭니다.

## 화면

### 🚀 로켓 조립
- 위쪽에서 반을 고릅니다. 반마다 진행 상황이 따로 저장되고, 반마다 처음부터 새로 시작합니다.
- 부품이 발사대에 도착한 것을 눈으로 확인한 뒤 강사가 **부품 번호 버튼**을 누릅니다.
  화면이 그 부품 자리로 확대되고, 부품이 날아와 붙으며 부품 카드(이름, 역할, 지역)가 나옵니다.
  잘못 눌렀으면 같은 버튼을 다시 눌러 취소합니다.
- 키보드로 번호를 쳐도 됩니다. 예: `2` `7` → 27번(잠깐 기다리거나 `Enter`). `Esc`는 입력 지우기, `스페이스`는 발사.
- 36개가 모두 모이면 완성된 로켓이 공개되고 인공위성이 실린 뒤 **🚀 발사대로 옮겨 발사하기** 버튼이 나옵니다.

### 🎬 발사 영상
발사대로 이송 → 기립 → “발사 준비 완료” 안내 → 누리호식 카운트다운(숫자와 음성, 현장음) → 점화와 이륙 →
구름 위로 상승 → 1단 분리 → 페어링 분리 → 2단 엔진 정지 → 인공위성 분리와 태양전지판 펼침 →
불꽃놀이와 마지막 자막(학교 이름 + “로켓 발사를 위해 최선을 다한 여러분에게 감사드립니다. / 로켓 발사 성공 축하합니다!”).

- `스페이스` 또는 ⏸ 버튼으로 잠시 멈춤, `Esc`로 닫기.
- 끝나면 **🎬 영상 파일로 저장**을 누르면 처음부터 다시 재생하면서 mp4(크롬 기준) 파일로 저장합니다.
- 음성 안내는 컴퓨터의 한국어 음성으로 읽습니다. 저장한 영상에는 이 음성이 들어가지 않고 화면 자막으로 남습니다.
  영상에도 목소리를 넣고 싶으면 설정의 **카운트다운 목소리 녹음**으로 강사 목소리를 녹음해 두세요.

### 🗺️ 경남 지도
- 실제 시군 경계(통계청 2013 경계)로 그린 경상남도 지도 위에 전지 6장 구역을 표시합니다.
- 세로 방향 전지(788×1091mm) 6장을 가로 3장 × 세로 2장으로 깔면 전체 지도가 됩니다(축척 약 1:66,000).
- 장 번호를 누르면 그 장만 크게 보이고 10cm 칸, 꼭 들어가야 할 내용, 그릴 그림, 이 장의 부품 업체가 나옵니다.
- **🔒 강사용** 버튼을 누르면 업체 이름, 업체 종류(누리호 참여 확인, 항공우주 기업, 닮은 기술 기업, 공공 시험기관,
  수업용 가상 업체), 근거 자료(출처, 링크), 힌트가 보입니다. 아이들이 조사한 뒤에 켜 주세요.

## ⚙️ 설정
- 학교와 반, 카운트다운 초(3~10), 효과음과 음성 켜기/끄기
- 마지막 자막 두 줄
- 카운트다운 목소리 녹음, 미리 듣기, 지우기
- 발사 장면 미리 보기(처음부터 / 카운트다운부터)
- 반 진행 초기화

## 내용 바꾸기

- 학교, 반, 전지 장별 내용, 시군 그림, 자막 기본값: [`js/data.js`](js/data.js)
- 부품 36개, 업체, 근거 자료, 발사대: [`js/parts.js`](js/parts.js). 수업 자료의 `companies.json`을 고친 뒤
  `python3 tools/import_companies.py companies.json js/parts.js`로 다시 만듭니다.
  부품이 로켓 그림의 어느 자리(zone)에 붙을지는 `companies.json`의 `zone`으로 정하고, 없으면 부품 이름으로 짐작합니다.
- 지도 경계: `tools/build_geo.py`로 만든 `js/geo.js`
