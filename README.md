# 경남 로켓 발사 프로젝트 · 전자칠판 화면

햄스터봇 창의융합 수업(초등 5·6학년)에서 전자칠판에 띄우는 화면입니다.
아이들이 햄스터봇 택배로봇으로 경남 곳곳의 부품 업체에서 로켓 부품을 발사대까지 옮기면,
화면의 로켓이 한 부품씩 완성되고 12개가 모두 모이면 발사 영상이 나옵니다.

## 여는 방법

- 설치가 필요 없습니다. 이 폴더를 USB나 전자칠판에 복사한 뒤 `index.html`을 **크롬(또는 엣지)** 으로 여세요.
- 인터넷이 없어도 동작합니다. (인터넷이 있으면 글꼴이 조금 더 예뻐집니다.)
- 오른쪽 위 ⛶ 버튼으로 전체 화면을 켭니다.

## 화면

### 🚀 로켓 조립
- 위쪽에서 반을 고릅니다. 반마다 진행 상황이 따로 저장됩니다(이 컴퓨터의 브라우저에 저장).
- 부품이 발사대에 도착하면 해당 부품 버튼을 누릅니다. 잘못 눌렀으면 다시 눌러 취소합니다.
- 키보드: `1`~`9`, `0`(10번), `-`(11번), `=`(12번)으로 부품 도착, `스페이스`로 발사.
- 12개가 모두 모이면 **발사 버튼**이 나옵니다 → 카운트다운 → 발사 영상.

### 🎬 발사 영상
카운트다운 → 엔진 클로즈업과 점화 → 발사대 연기와 함께 이륙 → 구름 위로 상승 → 1단 분리 →
우주와 지구 → 불꽃놀이와 축하 자막(“○○초등학교 학생들의 로켓 발사를 축하합니다.”).
끝나면 **🎬 영상 파일로 저장**을 누르면 처음부터 다시 재생하면서 mp4(크롬 기준) 파일로 저장합니다.
설정의 **발사 장면 미리 보기**로 수업 전에 확인할 수 있습니다.

### 🗺️ 경남 지도
- 실제 시군 경계(통계청 2013 경계)로 그린 경상남도 지도 위에 전지 6장 구역을 표시합니다.
- 세로 방향 전지(788×1091mm) 6장을 가로 3장 × 세로 2장으로 깔면 전체 지도가 됩니다(축척 약 1:66,000).
- 장 번호를 누르면 그 장만 크게 보이고 10cm 칸, 꼭 들어가야 할 내용, 그릴 그림, 이 장의 부품 업체가 나옵니다.
- **🔒 강사용** 버튼을 누르면 업체 이름과 근거 자료(출처, 링크)가 보입니다. 아이들이 조사한 뒤에 켜 주세요.

## 내용 바꾸기

수업 내용은 모두 [`js/data.js`](js/data.js) 한 파일에 있습니다.

- `schools`, `classes`: 학교와 반 (설정 화면에서도 바꿀 수 있음)
- `parts`: 부품 12개. `company`(업체 이름), `lon`/`lat`(업체 위치), `question`(아이들 조사 질문),
  `evidence`(근거 자료: `summary`, `source`, `url`)를 채우면 지도와 강사용 화면에 바로 반영됩니다.
- `sheets`, `mustCommon`, `landmarks`: 전지 장별로 꼭 들어갈 내용과 그림
- `launchSite`: 로켓 발사대 위치 (기본: 사천)
- `countdown`: 카운트다운 초

지도 경계는 `tools/build_geo.py`로 만든 `js/geo.js`를 씁니다.
